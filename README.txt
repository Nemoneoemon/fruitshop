HOW TO INSTALL (5 minutes)
1. Open https://app.netlify.com/drop on a computer (free).
2. Drag this whole folder onto the page. You get a link.
3. Open the link on your phone.
4. Chrome (Android): menu, then Add to Home Screen. iPhone Safari: Share, then Add to Home Screen.
5. Open the app once with internet. After that it works offline.

Your data is saved on the phone. Use Products > Save backup often.
